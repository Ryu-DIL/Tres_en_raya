# Tres en Raya (Tic Tac Toe) en Python

Este repositorio contiene dos implementaciones del clásico juego del Tres en Raya (Tic Tac Toe) desarrolladas en Python. Se ofrecen dos enfoques distintos: uno clásico basado en la terminal y otro más visual y moderno con interfaz gráfica.

## 🎮 Versiones Incluidas

### 1. Versión de Consola (Terminal)
- Se juega directamente interactuando con la línea de comandos.
- Modo de juego: Jugador contra Computadora.
- El tablero se dibuja mediante caracteres ASCII y permite introducir el número de la casilla (1-9) para colocar tu ficha.

### 2. Versión con Interfaz Gráfica (GUI)
- Desarrollada utilizando la librería estándar `tkinter`.
- Cuenta con un menú principal interactivo.
- **Single Player:** Juega contra la computadora.
- **Multi Player:** Juega contra otra persona en modo local.
- Incluye botones interactivos y ventanas emergentes (messagebox) para anunciar al ganador o empates de manera visual.

## 🚀 Requisitos

- Python 3.x
- `tkinter` (Normalmente viene incluido por defecto en las instalaciones de Python en Windows y macOS. En distribuciones basadas en Linux, es posible que necesites instalar el paquete `python3-tk` si no viene preinstalado).

## 🛠️ Cómo ejecutar el juego

Para ejecutar la **versión de consola**, abre tu terminal en el directorio del proyecto y ejecuta:
python nombre_archivo_consola.py
